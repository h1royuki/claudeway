# Claudeway

Аккаунты Claude Desktop и их лимиты в компактном меню macOS.

[English](README.md) · [Беларуская](README.be.md) · [MIT](LICENSE)

Нативное приложение на Swift/AppKit. Переключает аккаунты через штатный перезапуск
Desktop, сохраняет общие локальные настройки и согласует поддерживаемые Code-чаты.
Интерфейс на английском, русском и беларуском, значка в Dock нет.

## Возможности

- Несколько аккаунтов с локальными названиями, без повторного входа при каждом переключении.
- Лимиты на пять часов и неделю, точное серверное время сброса.
- «Запустить окно лимитов» вручную и «Автозапуск окон» после обновления статистики.
- Перенос локальных диалогов, включая незавершённые чаты с сохранённой перепиской.
- Уведомления только о добавленных и обновлённых чатах.
- Журнал восстановления, резервные копии и необязательный автозапуск при входе.

## Установка и сборка

Нужны macOS 13+, установленный Claude Desktop и выполненный вход. Для запуска окна
лимитов дополнительно нужен официальный нативный Claude Code CLI.

Готовый универсальный ZIP — во вкладке **Releases** репозитория. Приложение имеет
локальную ad-hoc подпись и не нотарифицировано Apple, поэтому Gatekeeper может
заблокировать скачанную сборку. Можно собрать проверенные исходники самостоятельно:

```sh
./test.sh
./build.sh
open "dist/Claudeway.app"
```

Для универсальной сборки: `ARCHS="arm64 x86_64" ./build.sh`. Нужны инструменты
разработчика Apple со Swift 5.9+. Для аудита и упаковки также требуется Python 3.

## Как пользоваться

Язык выбирается в **Настройки → Язык**: системный, English, Русский или Беларуская.
Выбор сохраняется и применяется сразу, без перезапуска Claude. По умолчанию язык
системный; для неподдерживаемого языка используется английский. Названия аккаунтов
не меняются. Даты и длительности следуют выбранному языку, часовой пояс — настройкам Mac.

При первом запуске сохраняется текущий вход Claude. Новые аккаунты добавляются
через «Добавить аккаунт…» и обычный интерфейс авторизации Claude. Выбор другого
аккаунта перезапускает весь Desktop; терминальная авторизация не меняется.

Лимиты обновляются раз в пять минут. «Автозапуск окон» проверяет выбранные аккаунты
после успешного обновления и отправляет один короткий запрос, если пятичасовое окно
не запущено. Расписания нет. Запрос расходует немного лимита; не увеличивает квоту
и не сбрасывает уже идущее окно. На новой установке функция выключена.

## Границы

Это независимая утилита, не продукт Anthropic. Она использует внутренний формат
Desktop; обновления Claude могут потребовать адаптации. Облачные Chat-диалоги,
владение Cowork, политики организации и подключения аккаунтов не объединяются.
Общие локальные файлы не изолируют аккаунты друг от друга.

Секреты обрабатываются только в памяти. Не публикуйте папку
`~/Library/Application Support/ClaudeSwitcher`, дампы Keychain, переписку или снимки
экрана с реальными аккаунтами. Подробности: [SECURITY.md](SECURITY.md).

чтобы существующие аккаунты и настройки оставались доступны.
