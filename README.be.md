# Claudeway

Акаўнты Claude Desktop і іх ліміты ў кампактным меню macOS.

[English](README.md) · [Русский](README.ru.md) · [MIT](LICENSE)

Натыўная праграма на Swift/AppKit. Пераключае акаўнты праз звычайны перазапуск
Desktop, захоўвае агульныя лакальныя налады і пераносіць падтрыманыя Code-чаты.
Інтэрфейс на англійскай, рускай і беларускай мовах. Значка ў Dock няма.

## Магчымасці

- Некалькі акаўнтаў без паўторнага ўваходу пры кожным пераключэнні.
- Пяцігадзінны і тыднёвы ліміты, серверны час скіду.
- Ручны запуск акна лімітаў і аўтазапуск пасля абнаўлення статыстыкі.
- Перанос лакальных дыялогаў, у тым ліку незавершаных чатаў з захаванай перапіскай.
- Апавяшчэнні толькі пра дададзеныя і абноўленыя чаты.
- Журнал аднаўлення, рэзервовыя копіі і неабавязковы запуск пры ўваходзе ў macOS.

## Усталяванне

Патрэбныя macOS 13+ і Claude Desktop з выкананым уваходам. Для запуску акна лімітаў
таксама патрэбны афіцыйны натыўны Claude Code CLI.

Спампуйце ўніверсальны ZIP з раздзела **Releases**, распакуйце яго і перанясіце
**Claudeway.app** у «Праграмы». Праграма мае лакальны ad-hoc подпіс без натарызацыі
Apple, таму Gatekeeper можа заблакіраваць спампаваную зборку.

Зборка з зыходнікаў патрабуе інструментаў распрацоўшчыка Apple са Swift 5.9+:

```sh
./test.sh
./build.sh
open "dist/Claudeway.app"
```

Універсальная зборка: `ARCHS="arm64 x86_64" ./build.sh`.
Для аўдыту і ўпакоўкі патрэбны Python 3.

## Выкарыстанне

Выберыце мову ў **Налады → Мова**: сістэмная, English, Русский або Беларуская.
Выбар захоўваецца і прымяняецца адразу, без перазапуску Claude. Калі сістэмная мова
не падтрымліваецца, выкарыстоўваецца англійская. Назвы акаўнтаў не змяняюцца.
Даты і працягласць паказваюцца на выбранай мове, часавы пояс бярэцца з налад Mac.

Пры першым запуску захоўваецца бягучы ўваход Claude. Новыя акаўнты дадаюцца праз
«Дадаць акаўнт…» і звычайны экран уваходу Claude. Выбар іншага акаўнта перазапускае
ўвесь Desktop; аўтарызацыя ў тэрмінале не змяняецца.

Ліміты абнаўляюцца прыкладна кожныя пяць хвілін. «Аўтазапуск вокнаў» адпраўляе адзін
кароткі запыт, калі свежыя даныя пацвярджаюць, што пяцігадзіннае акно не запушчана.
Запыт расходуе крыху ліміту; ён не павялічвае квоту і не скідае актыўнае акно.
На новай усталёўцы аўтазапуск выключаны.

## Межы і прыватнасць

Гэта незалежная ўтыліта, не прадукт Anthropic. Яна выкарыстоўвае ўнутраны фармат
Desktop; абнаўленні Claude могуць патрабаваць адаптацыі. Воблачныя Chat-дыялогі,
валоданне Cowork, палітыкі арганізацыі і падключэнні акаўнтаў не аб'ядноўваюцца.
Агульныя лакальныя файлы не ізалююць акаўнты адзін ад аднаго.

Не публікуйце даныя з `~/Library/Application Support/ClaudeSwitcher`, звязку ключоў,
перапіску або здымкі экрана з рэальнымі акаўнтамі. Пры абнаўленні захоўваюцца ранейшыя
каталог даных і ідэнтыфікатар праграмы. Больш падрабязна: [SECURITY.md](SECURITY.md).
