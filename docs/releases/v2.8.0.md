# Claudeway 2.8.0

A dedicated **Accounts** window replaces scattered add/rename actions.

- Open **Manage accounts…** from the menu bar.
- Rename any selected account in place and save without switching Desktop.
- Add accounts and complete or cancel sign-in in the same window.
- Remove accounts with confirmation. The current Claude login, chats and recovery
  backups remain on your Mac; removing the last account leaves an empty list.
- Empty lists provide a clear entry point to add the first account. Fresh installs
  no longer capture an account automatically.
- Available in English, Russian and Belarusian.

## Downloads

- `Claudeway-2.8.0-macos-universal.zip` — macOS 13+, Apple Silicon and Intel.
- `claudeway-2.8.0-source.zip` — source code under MIT.
- `SHA256SUMS` — integrity checks for both archives.

The app is ad-hoc signed and **not notarized**. Quit the previous Claudeway instance
before replacing the app. Existing accounts/settings are retained. Empty/untracked
account states require version 2.8 or newer; do not downgrade after using them.

This independent utility uses undocumented Claude storage/endpoints. Automatic
window starts use the official Claude Code CLI and consume a small amount of usage.
