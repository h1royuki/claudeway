# Claudeway 2.6.0

Native macOS menu-bar account switching and usage information for Claude Desktop.
This is the first publication-ready community release. The UI is in Russian.

## Included

- Claudeway branding, with existing profiles/settings preserved on upgrade.
- Removed the built-in instruction page and its menu item.
- Recoverable account switching with one shared local workspace.
- Compact five-hour/weekly usage and server reset times.
- Local Code history reconciliation, including unfinished conversations.
- Manual «Запустить окно лимитов» and optional «Автозапуск окон» after usage refresh.
- Transfer notifications with added/updated counts only.
- Source code, tests, MIT license and public privacy/release tooling.

## Downloads

- `Claudeway-2.6.0-macos-universal.zip`: macOS 13+, Apple Silicon and Intel.
- `claudeway-2.6.0-source.zip`: clean source export, without Git history or local data.
- `SHA256SUMS`: integrity checks for both archives.

The app is ad-hoc signed and **not notarized**. macOS may block a downloaded build.
Building from source is an alternative; see README. Claude Desktop must be installed
and signed in. Automatic window starts additionally require the official native
Claude Code CLI and consume a small amount of usage. They are off by default.

## Compatibility and verification

This release uses undocumented Claude storage/endpoints and is not affiliated
with Anthropic. Cloud conversations, Cowork ownership and account connectors are
not shared. Tests use synthetic data, and production packaging is scanned for
common personal-data/secret patterns. See `docs/privacy-audit.md` for the audit
scope and limitations; a checksum is not publisher authentication.

Release maintainers should inspect the CI results for both architectures and the
draft artifacts before publishing. Do not interpret a cross-compiled Intel binary
as proof of an Intel runtime test.
