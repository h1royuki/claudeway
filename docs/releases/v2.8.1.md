# Claudeway 2.8.1

Keychain authorization now happens at startup instead of during usage refreshes.

- First probe silently; if access is already granted, no dialog appears.
- Ask once when permission is needed, independently of Internet connectivity.
- After a refusal, usage refreshes and window-start requests remain noninteractive.
- Retry explicitly through **Settings → Keychain access…**.
- Choose **Always Allow** in the macOS dialog to retain access between launches.

This version also includes the Accounts window from 2.8.0. Existing profiles,
chats and language preferences are preserved. Builds are ad-hoc signed, not
notarized; macOS controls Keychain prompts and persistent access decisions.
