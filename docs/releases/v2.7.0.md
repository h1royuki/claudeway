# Claudeway 2.7.0

Claudeway now speaks English, Russian and Belarusian.

Choose **Settings → Language** / **Настройки → Язык** / **Налады → Мова**.
The default follows your Mac's preferred languages, with English as the fallback.
An explicit choice is saved and applies immediately, without restarting Claude.

- Menus, settings, errors, notifications and accessibility labels are translated.
- Reset dates and compact durations follow the selected language.
- Existing Russian statuses and usage labels translate when displayed. Account
  names, login state, chats and request deduplication records are preserved.
- Packaged translations are verified alongside the synthetic test suite.

## Downloads

- `Claudeway-2.7.0-macos-universal.zip` — macOS 13+, Apple Silicon and Intel.
- `claudeway-2.7.0-source.zip` — source code under MIT.
- `SHA256SUMS` — integrity checks for both archives.

The app is ad-hoc signed and **not notarized**. Gatekeeper may block downloaded
builds. Quit the previous Claudeway instance before replacing the app. Existing
profiles/settings use the same storage and bundle identifier.

This independent utility uses undocumented Claude storage/endpoints. Cloud Chat,
Cowork ownership and account connectors are not shared. Automatic window starts
use the official Claude Code CLI and consume a small amount of usage.
