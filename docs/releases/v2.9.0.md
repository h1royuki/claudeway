# Claudeway 2.9.0

Choose which projects share local Code chats between accounts in
**Settings → Chat transfer…**. Keep all projects, choose individual folders with
search and checkboxes, or disable transfers entirely.

Selections apply to both new chats and metadata updates during the next switch.
Existing chats are preserved. New projects are included automatically only in
all-project mode. No project files, cloud chats or account permissions are copied.
All new controls are translated into English, Russian and Belarusian.

Validation: 76 synthetic test groups, universal arm64/x86_64 compilation, packaged
localization checks and the offline publication audit. Intel execution and real
account switching were not tested for this change.
